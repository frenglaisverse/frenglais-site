Vue d'ensemble

Afficher mes mails non lus ici · à faire une seule fois, 3 minutes
  1. Ouvrez api-console.zoho.eu ↗ avec votre compte Zoho, cliquez « Add Client », puis « Self Client », puis « Create » (si un « Self Client » existe déjà, ouvrez-le simplement).
  2. Onglet « Client Secret » : copiez le Client ID et le Client Secret dans les cases ci-dessous.
  3. Onglet « Generate Code » : dans « Scope », collez ZohoMail.accounts.READ,ZohoMail.folders.READ,ZohoMail.messages.READ,ZohoMail.messages.CREATE , choisissez 10 minutes, écrivez « Tableau de bord » en description, puis « Create ». Copiez le code obtenu ci-dessous.
  4. Cliquez « Connecter ». C'est fini : le nombre de mails non lus s'affichera sur le bouton « Mes mails ».

Ces informations partent directement sur votre serveur Cloudflare, protégées par votre clé ; elles ne sont jamais enregistrées sur le site ni dans ce navigateur.
